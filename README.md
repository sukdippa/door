## Door

Next.js starter with a Three.js WebGL hero and GSAP ScrollTrigger animations.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the app.

Start editing the page by modifying src/app/page.tsx. The page auto-updates as you edit.

## Stack

- Next.js App Router
- GSAP + ScrollTrigger for scroll animations
- Three.js for WebGL rendering

## Production Build

```bash
npm run build
```
